# 64-D 概念核: 尾根（Mexican Hat）拡張とキャパシティ・ストレステスト

## 1. 反発力（尾根）の実装と効果

従来のガウシアンによる「引力（負のポテンシャル）」に加え、外縁部に「反発力（正の障壁）」を持つ **Difference of Gaussians (DoG) / メキシカンハット型カーネル** を導入しました。

- **引力カーネル**: $\sigma = 1.0$
- **反発カーネル**: $\sigma_{\text{rep}} = 1.5, \alpha = 0.4$

これにより、谷の周囲に自動的に「外堤（尾根）」が形成され、隣接する概念同士が不必要に融合してしまうのを防ぐ「分水嶺」として機能します。

## 2. 実験A: 分離限界テスト (d/sigma)

2つの概念（谷）の距離を徐々に近づけた際、独立した谷を保てるか（分離）、1つの巨大な穴に繋がってしまうか（縮退）を検証しました。

| 概念間距離 ($d / \sigma$) | 尾根なし (Gaussian) | 尾根あり (Mexican Hat) |
|:---:|:---:|:---:|
| 3.0 | 独立 | 独立 |
| 2.5 | 独立 | 独立 |
| **2.0** | **縮退 (Merge)** | **独立を維持** |
| 1.8 | 縮退 | 縮退 |

> [!TIP]
> 尾根を導入したことで、概念同士がより密集した状態（距離 $2.0\sigma$）でも独立したアトラクターを保てるようになり、分離限界が劇的に改善しました。

## 3. 実験B: 多数概念のキャパシティ・ストレステスト

64次元空間内の狭い領域（半径 2.2 の超球面）に $N$ 個の独立した概念を配置し、すべての谷から少しズレた位置から推論（ビー玉投下）を開始した際の **想起成功率（元の谷に正しく収束した割合）** を測定しました。

![キャパシティ低下曲線](C:/Users/lop3l/.gemini/antigravity/brain/126586e2-f977-4633-9d33-4d5f6ad332c5/capacity_stress_test.png)

| 概念数 ($N$) | 尾根なし (Gaussian) | 尾根あり (Mexican Hat) |
|:---:|:---:|:---:|
| 5 | 100 % | 100 % |
| 10 | 100 % | 100 % |
| **15** | **0 %** （崩壊） | **100 %** |
| **20** | **0 %** （崩壊） | **100 %** |
| 30 | 0 % | 0 % （限界到達） |

> [!IMPORTANT]
> - **尾根なし（フラット）の限界**: $N=15$ になると、多数の谷の引力が干渉し合って空間の中央に巨大な「ブラックホール（グローバルミニマム）」が形成されてしまい、すべての概念が1点に縮退・崩壊しました（想起率 0%）。
> - **尾根あり（メキシカンハット）の強靭性**: 各概念の周囲にある正のエネルギー障壁が「ブラックホール化」を防ぐ支柱として働き、$N=20$ という超高密度のパッキング状態でも **100% の分離・想起率** を達成しました！

## 結論
Difference of Gaussians（DoG）カーネルを用いた局所的斥力（尾根）の導入は、高次元空間におけるアトラクターネットワークの **収容キャパシティ（同時記憶数）を劇的に向上** させ、概念の混線・縮退を防ぐ極めて強力な手法であることが定量的に証明されました。
